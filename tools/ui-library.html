Main menu panels

Fonts

Each face is loaded from assets/fonts through the game's own stylesheets. Pixel faces only at whole multiples of their grid (HUD-STYLE "Crisp sizes only").

Working colours

HUD-STYLE "Working colours". A working palette, not a frozen one: every colour has a job. B/W colours come in pairs (a bright fill over a dark shade), shown as a split swatch.

Type palette canonical for all UI

Bulbapedia Scarlet/Violet. Base for fills, Dark for shades and outlines, Light for highlights and for type-coloured text over the map. Read live from G.U.TYPE_COLOR, TYPE_COLOR_LIGHT and TYPE_COLOR_DARK (js/core/util.js).

Styles

Looks that are not kit components. The type chips, toasts and HUD text use the game's real CSS classes; the rest are drawn here from HUD-STYLE values (the live components are in Components above).

Life meters and bars

B/W thresholds: green above 50%, yellow 50% to 20%, red below 20%. Fill over shade on the empty track.

Status chips (70 x 24)

Majors are solid (fill over shade), on the left. Minors are hollow (a #101010 body in a rim of their own colour), in the character info panel only.

Effect chips

Good band above, bad band next to the life meter. Stat chips are the stat's Base over Dark (UI-PALETTES "Pokemon Stats"); type guard chips are the type's SV Base over Dark.

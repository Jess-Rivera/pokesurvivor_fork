Grep the 'move:hit' consumers (move-render overlay, harness tape checks) and confirm none assumes dmg above 0. Props still emit nothing.
- P5 Riders skip a dead target and a remote (co-op) copy. A rider that targets the hit enemy fires only for an enemy hit that actually landed in the sim (never for props).

## Build (all behind the flag; flag off must behave exactly as today)
1. js/systems/move-effects.js. One applier per effect type in the existing table (I3), each reading its own effect only:
   - A single chance helper: absent chance means guaranteed (no roll); otherwise percent divided by 100, times 0.5 to the power hop (the chain halving hook from D15; hop is 0 until 4b), one roll from the injected rng (I7, I9). Every eligible hit rolls its riders (Q14).
   - damage: capture the enemy's HP and shield before the hurt call and the damage actually dealt after it (HP lost plus shield lost; overkill excluded, as legacy drainHeal), apply P2 and P3, and return the actually-dealt amount for heal.
   - ailment: map the id to the existing entry points (burn to applyBurn, poison to applyPoison, paralysis, freeze, sleep, confusion and trap to applyStatus). Strength multiplier 1 and duration multiplier 1 (upgrade cards are ignored until slice 5). Type immunity, 'blocked' and the freeze and sleep windows are already inside those functions; do not duplicate them.
   - flinch: Enemy.applyFlinch on a successful roll.
   - stat: one function maps the schema stat to the stages.js key (D31: atk to atk, def to def, spAtk to spa, spDef to spd, spd to spe) and nothing else translates. Host by side and scope: foe applies to the enemy's own list; self team uses the owner's team store; self individual uses the owner's own list. Duration comes from the resolved effect (6 s default), the cap from maxStacks (6 default), the source tag is the move id.
   - heal (from dealt only): HP actually removed times fraction times 1.3 with Big Root (pl.bigRoot), through the player's heal. No cap, as legacy Giga Drain (on purpose). The maxHP-per-second form (Aqua Ring) is 4b.

WHAT TO CHECK
For each in-scope doc, find places where it:
A. Contradicts a source of truth (a number, default, enum, field name, rule or sequence that differs). Quote both sides with file and line or heading.
B. Restates rule text that now lives elsewhere, instead of pointing to it. CLAUDE.md says CONTEXT, STATE, slice-overview and DECISIONS do not restate rule text. Flag restatements in planning docs that could drift.
C. Cites a document, section, decision ID (D-numbers, Q-numbers, QA-numbers, S-numbers) or path that no longer exists, moved, or now means something else. Verify each cited path resolves and each cited ID exists where claimed.
D. Uses a requirement tag wrong: an approved rule shown as proposed, a proposed rule written as settled, an approved-but-unbuilt rule missing the "code differs, see TODO" note, or a legacy behavior without a named removing slice.
E. Conflicts with another planning doc in the same folder (for example a 4c handoff versus slice-4c.md versus combat-architecture, or a later slice reversing an earlier locked decision without saying so).
F. Is superseded: a doc or section whose content is fully covered by a source of truth and should be marked historical, trimmed to a pointer, or moved.
G. Violates house rules in newly written text: em-dashes (not allowed outside archive copies), new Spanish user-facing strings, confirm/alert/prompt instead of G.UI.ask, stat formulas outside G.Stats, anything touching the deferred cloud and multiplayer scope.

  on the run clock with the green arrow ("Catch"); touching it opens the catch screen with the run paused, as a shop does.
  Not reached in time, it wanders off. An empty belt at the win: it runs off at once (spec).

  Flee pips, the belt strip. A click or number key selects; Throw, Enter or a double click throws; a short three-wobble beat.
  Let it go (or Esc) asks once, then it runs off and the balls stay.
- The belt refills to its size at each run start until #137 brings the Shop restock ([Legacy behavior], removed by #137).
- FB4: every other run ending keeps catches. FB5: End Run loses them (as EVs); the keep flag is the EV flag. FB6: Run Info shows
  "Caught this run".
- A full box at the run end sells the overflow with a notice; the keep-or-sell list is its own issue (#146).
- Odds as a whole percent; 90% ceiling and flee 5 / 3 / 1 stay playtest values.

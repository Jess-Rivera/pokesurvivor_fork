# 2026-11-15, #124: Silver is 1 per kill from 0; move prices fall by slots filled, Trainer below the TM Mart (Jess)

Replaces the 5 x world level x character level price, the world level / 10 kill pay and the starting 100.
- Silver is kill based: one defeated Pokemon pays 1, whatever its HP, species or the enemy mix. A run starts with 0.
- Move prices reward breadth first. The discount follows the member's slots filled, so a member starting with 2 moves skips
  the first step. Move Trainer: base 300, discounts 80 / 60 / 20 / 0 percent (60, 120, 240, 300). TM Mart: base 450,
  discounts 66 / 33 / 11 / 0, taken as thirds and ninths (150, 300, 400, 450).
- A forget-and-replace always pays the full base; the count never drops back.
- Difficulty pays directly: elites, bosses and special encounters pay 1 plus a fixed bonus, sized after a traced run reaches gym 1.
Keeps 2026-11-15-124-economy-independent-of-xp.

## 2026-11-10, The Bulbapedia Scarlet/Violet type palette is canonical for the HUD and all UI (Jess)
Type colours in the HUD and every UI screen come from the Bulbapedia SV palette, three tones per type (light, base, dark). It agrees with mainline (Fire red, Fighting orange), unlike today's `G.U.TYPE_COLOR`, which has them swapped.
The game-wide switch of `G.U.TYPE_COLOR` is #68; recolouring the gym buildings to match is #69 (the roof prototype preserved shading cleanly). The B2 battle rip stays the reference for how a type shows (a coloured rim on a dark checker body).
Canonical: docs/HUD-STYLE.md "Colour palette".

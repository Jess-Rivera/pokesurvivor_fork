# 2026-11-12, Region type maps: 9 maps per region, cast fill rules (Jess)

Each region gets 9 maps, each focused on 2 or 3 types (a mix of both), themed as a biome ("Meandering Meadows", "Dark Volcano"). Feeds a later Pokemon acquisition mechanic.
- D1 fill: on-type species fill a tier's cast first; off-type species from the region fill only the missing families (melee / range / support). Same idea as the gym off-type fill rule.
- D2 weighting: own gen first; earlier gens appear only when the own gen is short.
- D3 types per map: some 2, some 3.
- Layout (Jess, same day): maps 1-8 split all 18 types (each type once); map 9 holds the Stage 3 and high-BST species.

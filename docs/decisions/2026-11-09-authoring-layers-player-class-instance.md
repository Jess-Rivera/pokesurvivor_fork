## 2026-11-09, Authoring layers: Player, then class, then instance (Jess)
Clarifies the leader principle's "hand authored". A Player entity's rules come in three layers: the Player parent (your rules), then its class's authoring (for example every World Boss is a raid fight), then its instance's authoring (a gym, or "Gyarados, World Boss"). A layer with no authoring falls through to the one above; with none at all, the Player parent's rule (or its absence) applies. Class-level authoring is allowed, but it lives in one declared list of differences per class, never as checks scattered in code, so every difference stays visible and countable. Replaces the branch rules' "authored per subtype or more restrictive level" wording.

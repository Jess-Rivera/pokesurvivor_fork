5. Sim inside this file

  • All timers, windows, grace
  • One-major rule, immunities, berry guard
  • DoT ticks into takeDot
  • Movement answers: stunned, rooted, speedMul, wander, jitter
  • Fizzle roll, sleep chance, swap lock, Shake off

Presentation mixed in

  • text() → G.FX.dmgText: "Immune" (apply, applyDot, immuneNote), labels on a new status, "Fizzled"
  • anim.frozen written in tick and clear
  • Labels and colors in CONTROL; TINT, tintOf, AIL_COLOR, ailColor
  • list() builds HUD label text

Candidates for SimBus events (SIM-PRESENT-BOUNDARY), like gym.js already did.

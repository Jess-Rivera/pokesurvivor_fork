6. Where the spaghetti is

#TangleWhereUntangle by
1Two status systems in one mon. Burn and poison tick in update() on slice A fields; everything else ticks in G.Status.update 551-578, applyBurn, applyPoisonwild mons on stDot like the player
2Visuals inside the rules. About 27 G.FX, 35 animator, 16 camera and 6 audio calls spread over 20+ methods.hurt, showHurt, die, update, healAround, summon, shoothit, die, cast events on SimBus
3Co-op woven through. 34 G.Coop and 19 remote references; hurt and die each fork for a copy.hurt, die, netUpdate, manager add/remove/replaceone replication layer that reads state (multiplayer phase)
4One 329-line frame. 9 early exits, then a 6-way movement choice, keyed on 9 behavior strings checked 23 times.update 526-854split think / move / animate; a behavior table instead of string checks
5Game logic reads the camera. Spacing bands are measured in screen units, and stragglers teleport based on what is on screen.screenDist, bandPx, manager update 1870-1881world-unit bands; a "view" value passed in
6Hitbox from sprite art. Collision radius and body height come from sprite metadata.constructor (4 sprite reads)a body-size data table (already a TODO)
7die() reaches out. Pulls the player, every player, items, spawner and a global shiny hook.die 429-473die emits; listeners pay the snowball, XP and shiny
8Fields appear from outside. invuln, remote, leaving and life are set by other files and never declared here.move-sim, coop, elites, spawnerdeclare them in the constructor

WhatWhy it might matter
hurt() line 236 says i-frames let damage over time through, but dot() calls hurt(), which returns while invuln > 0the comment and the code disagree. Possibly moot if only leaders get i-frames and leaders no longer use this body.
Morale pain and fear only decay inside the band movement brancha mon without a band keeps whatever pain it collected. Fine if only band mons ever read morale.
Band mons shoot from inside the movement brancha stunned-then-freed or flinching band mon's shot timing is tied to movement code; easy to break when splitting update()

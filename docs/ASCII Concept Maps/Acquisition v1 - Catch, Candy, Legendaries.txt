ACQUISITION v1: CATCH, CANDY, LEGENDARIES (2026-11-12, design only, no code)
============================================================================
Direction (Jess, 2026-11-12): remove the gacha. A gacha pull can hand out an end-game mon
(Mewtwo) on luck, which undercuts Pokemon investment and makes starters useless.
Replace it with 3 tiers. Region type maps (Biomes v2) are parked; they feed tier 1 later.

THE THREE TIERS
---------------
  TIER 1  IN RUN: CATCH (Stage 1 only)
    rare event ──toast "[Stage 1] needs help!" + arrow (like shops / gyms)
         │
         ▼
    UberElite guards it (above an Elite, near a strong Gym Leader mon)
         │ defeat it under X seconds?
         ├─ no  ──> the Stage 1 runs off, no catch
         ▼ yes
    catch phase: throw Poke Balls from the Pokeball Belt
         ├─ catch ──> new unique copy in the Pokebox (IVs, nature, as today)
         └─ fail  ──> Flee meter rises ──full──> it runs away
    Pokeball Belt: 1 ball per run at the start, more via meta progression

  TIER 2  META: EVOLUTION BY CANDY (the only route past Stage 1)
    Gym Leader ──drops──> Exp Candy (mainline XS / S / M / L / XL)
         │
         ▼  (main menu)
    feed a copy ──> permanent candy level ──reaches evo point──> evolves (Stage 2, Stage 3)
    runs still start at level 1

  TIER 3  LEGENDARIES (approved already, GDD 12, unchanged)
    clear Loop 6 in one sitting ──> Legendary Boss ──win──> that legendary joins your Pokedex

  rarity 1-5 field: drives gacha odds, sell price (15/30/60/120/300) and the spawn rule (< 5)

FEEL RISKS
----------
  * Belt = 1 means no retry: one failed throw after beating the UberElite wastes the
    whole event. "Keep attempting until it flees" only exists from belt 2 up.
  * Rare event x timer x catch chance x 1 ball = a slow trickle. Kanto has 74 to catch.
    New accounts could go many runs with nothing new. (VS rule: no zero-progress runs;
    candy from gyms covers that only if you already own something worth feeding.)
  * UberElite in the middle of a run: a hard DPS check (the "boss tests your build"
    pitfall). Telegraphed patterns or a gym-leader-style moveset keep it skill-based.
  * Evolution power is permanent and stacks with the in-run curve: an evolved team's
    base stats rise for every run after. That IS the investment loop, so budget it in BALANCE.

RESOLVED (Jess, 2026-11-12)
---------------------------
  A11 Belt 1: a missed throw ENDS the event. Retries (and the Flee meter) only exist from belt 2 up.
  A5  Strong never-evolving Stage 1s (Snorlax, Lapras, UBs, Paradoxes): catchable, gated by capture_rate.
  A10 Permanent candy level = evolution meter ONLY. No stats; every run still starts at level 1.

  This reopens A11: with 6 balls a miss no longer ends the event, the Flee meter does.
  Belt size only matters when it runs out before the Flee meter does:
     balls per run  vs  events per run x throws before a flee
  With 1 to 2 rare events per run and a Flee meter of ~3, a 6-ball belt is rarely empty,
  so buying more belts would add little. The real knobs become Flee capacity and catch odds.

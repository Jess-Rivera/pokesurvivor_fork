NEW DEFAULTS AND RULES  (each needs your OK on its own)
-----------------------------------------------------------------------------------------------------
 DS1 RULE  Silver "earned" = what kills paid this run. The starting 100 is NOT earned; G.Debug.silver(n)
           counts as neither earned nor spent. "Spent" = successful spends only. <- rec
           (b) earned includes the starting 100
 DR1 RULE  REGION BEST reads as a pace delta, speedrun style (LiveSplit's "delta").  [reworked per Jess]
           A milestone = a gym beaten, in order (loop 1 gym 1, gym 2 ... then loop 2 gym 1 ...).

           |  REGION BEST                                                       |
           |  Best             Loop 3, Gym 3 cleared, lasted 85:10  (DR5)       |
           |  Next             Loop 1, Gym 3  (best got there at 14:20)         |
           |  Pace             You're ahead by 1:12                (green)      |

           How Pace is worked out at the moment you pause (now = run time):
             k = the last milestone this run beat (none yet = 0)
             live  : now is past the record's time for milestone k+1 and you have not beaten it
                     -> "You're behind by (now - best[k+1])"   (grows the longer you take)
             split : otherwise, your time at k vs the record's at k
                     -> mine < best: "You're ahead by", mine > best: "You're behind by", equal: "Even"
             no k yet and not live -> "On pace" (nothing to compare yet)

           TIMELINE (record: G1 4:52, G2 9:10, G3 14:20)
             run time  0 ........ 4:30 G1 ....... 9:50 G2 ........ 14:20 ..... 15:05 (paused)
             you        G1 at 4:30 -> ahead 0:22    G2 at 9:50 -> behind 0:40
             at 15:05, G3 not beaten, best had it at 14:20 -> live: "You're behind by 0:45"

           Edges: no record -> "No record yet", Next and Pace hide.
                  past the record's last milestone -> Pace: "New best pace" (gold), Next hides.
                  the record ran on Loop 3 but loops are dev-set today: in practice Loop 1 gyms only.
           Colours: ahead green, behind red, even / on pace white. Times always mm:ss, minutes past 59 (82:30).
           <- rec   (b) split only, never live (the delta only moves when you beat a gym)

 DR3 RULE  [Approved, Jess 2026-11-12] same furthest place, the tie splits by how the run ended there:
             both CLEARED the same gym, then died in the field -> the later run end wins (survived longer)
               best cleared L3 G3, ended 85:10   you cleared L3 G3, ended 85:13   -> you are the new best
             both DIED IN the same gym's fight                -> the sooner arrival at that fight wins
               best died fighting L3 G3, fight began 82:30   you, began 80:05  -> you are the new best
             exact tie -> the old record stays.

 DR4 RULE  [Approved, Jess 2026-11-12] Does dying INSIDE a gym fight rank above clearing the gym before it and dying in the field?
             ladder (rec):  ... < cleared L3 G2 < died fighting L3 G3 < cleared L3 G3 < died fighting L3 G4 ...
             you cleared L3 G2 and died in the field at 95:00; best died fighting L3 G3 at 82:30
               rec (a): best stays (reaching the fight is further)    (b): field vs fight do not matter,
               only gyms cleared count, so these tie on "2 cleared" and fall to DR3, which has no rule for
               a cleared-vs-fight mix  <- (a) recommended

 DR5 RULE  [Approved, Jess 2026-11-12] Best row wording, since its time now means two things:
             cleared:   "Loop 3, Gym 3 cleared, lasted 85:10"
             in fight:  "Died at Loop 3, Gym 4, reached it 82:30"  <- rec
             (b) one short form for both: "Loop 3, Gym 3  85:10" 
 DR2 RULE  Region Best is set by SOLO runs only (co-op is deferred; a co-op run never writes it). <- rec
 DH1       Biggest hit tie: the first hit keeps it (as built in 91-1). <- rec   (b) the later one
 DK1       Kills per minute under 1 minute of run time: shown as "--" until 1:00. <- rec
           (b) project from the seconds played (reads wild early: 12 kills in 5 s = 144/min)

MOVE SHOP STEP 3: BUILDINGS AND ARROWS   (plan, 2026-11-05, APPROVED as proposed by Jess, BUILT the same day)
Spec: docs/proposals/move-shop-plan.md "Shops on the map". Handoff: docs/proposals/move-shop-handoff.md.
Shop SCREENS are step 4. In this step you can see, find and walk into the buildings; see F2 for what
walking in does until step 4.
Existing behavior changed by this step: the GYM ARROW (F1). Nothing else that exists changes.

=====================================================================
 1. TIMELINE (one run)
=====================================================================

  0:00 ─── 2:00 ════ 3:00 ─────── 4:00 gym 1 gate ... win ─┐
           │ both    │ both gone   (gate stays until        │ back on map
           │ spawn   │ (1 min)      entered, as now)        │
           └─────────┘                                      ▼
                                       return ── +90 s ════ +150 s ── +240 s next gate
                                                 │ both    │ gone
                                                 └─────────┘
  Repeats after every gym return. Shops and a gym gate never overlap in
  the normal schedule (shops end 1:00 before gym 1, and 1:30 before every
  later gate), so the two arrow types are almost never on screen together.

  "1 minute" is the run clock: it stops in pause, level-up and any menu.

 2. PLACEMENT
=====================================================================

                       Move Trainer
                           [M]
                            \
          view circle  .-----\-----.
                     /        \      \      both doors farther than
                    |    (you) ●      |     view radius + 140 world px
                     \        /      /      (fully off screen, any window)
                      '------/------'
                            /    bearings more than 90° apart
                          [T]    (second = first + 100° to 260°)
                       TM Mart

  distance   view radius + 140 to + 320 world px      (TUNE)
             view radius = G.Camera.outerRadius() (half the view diagonal + 40)
             walk at median speed (107 px/s): about 3 s past the screen edge
  ground     every sample of the building's contact area on free ground
             (the same check the gym gate uses)
  retry      24 random tries per shop; if either fails, both retry in 2 s
             (as the gym gate's caller does). The minute starts when placed.
  art scale  1.5 to start (Trainer 117 x 108, Mart 96 x 107 world px; the
             gym is 144 x 124). TUNE by feel. Kept at 1.5 (Jess 2026-11-05).

 6. DECISIONS FOR JESS (each separate)
=====================================================================

  F1  THE GYM ARROW MOVES   (CHANGES EXISTING BEHAVIOR)
      The spec approved "both arrows float about 60 px off the character"
      (2026-11-04). Flagged here because it changes the gym arrow you
      already play with.
      proposed:  yes, the gym's off-screen arrow floats off the character
                 like the shops', purple, same label text. On-screen bounce
                 marker unchanged.
      alt:       gym arrow stays at the screen edge; only shops float

  F2  WHAT WALKING IN DOES UNTIL STEP 4
      proposed:  a one-line toast ("Move Trainer: opens soon" /
                 "TM Mart: opens soon"), no pause, step-off rule applies.
                 Proves entry works now; step 4 swaps in the screen.
      alt:       nothing at all until step 4

  F3  EXPIRY CUE   (new, nothing existing changes)
      proposed:  label shows seconds left; it blinks for the last 10 s;
                 the building fades out over the last 1 s.
      alt:       no warning, it just vanishes at 1:00

  F4  SHOPS DURING A GYM ARENA   (cannot happen in the normal schedule)
      proposed:  guard anyway: in an arena the shops are hidden and their
                 minute stops; back on the map they resume.
                 A shop time that falls inside an arena waits for return.
      alt:       an arena removes any shops on the map

  F5  CO-OP   (deferred)
      proposed:  no shops in co-op until co-op shops exist; one line in
                 TODO.md under deferred. (Silver is already hidden there.)

  NEW HARNESS   docs/proposals/shops-harness.js   (check.js finds it by name)
     checks, all expected values hand-derived from this map and the spec:
     - schedule: none before 2:00; one Trainer and one Mart at 2:00; no

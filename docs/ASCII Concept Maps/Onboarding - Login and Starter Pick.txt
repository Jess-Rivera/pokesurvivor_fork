F2  TAB (root cause found)
==========================================================================
  js/core/input.js keydown listener, about line 136:
    blocks the browser default for arrows, Space and Tab on EVERY keydown, everywhere,
    so the page never moves focus. Tab is also bound to cycle_next (with E) in runs.
  Same listener also means: Space cannot be typed into the name field and the arrow
    keys cannot move the cursor in it. Testers likely hit this too.

  Change: when the key event comes from a text field (input, textarea, select, or
    contenteditable), skip the block and let the browser handle it. Everywhere else
    (canvas, a run) it behaves exactly as today, so Tab still cycles targets in a run.
  Rule change for approval: D4.

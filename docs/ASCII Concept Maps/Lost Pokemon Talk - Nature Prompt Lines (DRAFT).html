How a talk is assembled

Toast names the nature→ P1 opener (nature pool)→ 3 approaches: the liked one + 2 others→ P1 reaction (nature × like / neutral / dislike)→ P2 opener (nature pool)→ 3 berries: the liked one + 2 others→ P2 reaction→ Roll at final favor

Variety rules [Proposed]: each slot draws from its pool with a per-run shuffle bag, so no line repeats until its pool runs dry. Like and dislike lines are written to the one approach or berry that triggers them, so they can name it. Neutral lines must fit any of the 3 other options, so they stay generic. Every line is game narration about wordless behavior: no quoted speech and nothing about code (docs/META-NARRATIVE.md).

Natures

Open points for review

  • Body plans. The pool includes floaters (Zubat, Gastly). Lines avoid paws, tails and feet, but "sits", "lies down" and "rolls over" still read a little oddly on a floater. Option for later: add a floater variant for those few lines.
  • Neutral natures (Hardy, Docile, Serious, Bashful, Quirky) like whatever matches the species' highest non-HP base stat (build path D2 b), so their like lines are generic and they have no dislike lines. The sample roll below picks a random stat to stand in for that.
  • Neutral is the most common outcome, since 2 of the 3 options on each prompt are usually neutral, so every nature has 2 neutral lines per prompt. If playtests show repeats there first, that pool is the one to grow.
  • Length. Lines are flagged red if they pass 72 characters with a 10-letter name in place of {name}. That limit is a guess for the talk window width.
  • Two nature models. The catch screen's flee buckets (catch.js) don't follow raised stats, so a Timid Pokemon is hard to catch but loves Play chase here. That needs one decision at the #148 tuning pass.

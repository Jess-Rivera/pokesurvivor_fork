=====================================================================
 THE LOOP  (per the draft)
=====================================================================

   IN A RUN                         RUN ENDS                     ALLOCATION SCREEN
   --------                         --------                     -----------------
   any enemy dies                   death or quit (F3)           six banks, whole part only
     |                                |                            HP   1   (0.46 lost)
     v                                v                            Atk  2   (0.55 lost)
   its species' TYPED yield x       banks frozen                    ...
   its class rate (F1) into that    fractions shown as lost        Spe  2   (0.11 lost)
   bank (six banks, separate)                                     team copies as columns:
   (Pidgey: Spe +0.001)                                            [-] n [+] per copy per stat
                                                                   252 / 510 caps per copy
                                                                   [Done] -> leftover discarded
                                                                   (confirm if any left, F5)
                                                                      |
                                                                      v
                                                                 EVs saved on each copy (key 'e',
                                                                 already in the save), apply from
                                                                 the next run, all six stats (F7)

   No new save key: the banks are run-only. Old copies have no 'e': 0. No migration.
   Banks count in whole thousandths (integers): 1000 wild Pidgey, 500 shiny ones, or 1 gym Pidgeot
   (Spe 2 at 1x) are exact.

=====================================================================
 WHAT THE RATES GIVE  (estimates: Kanto mean yields, 1.7 kills/s from BALANCE.md)
=====================================================================

   mean yield per kill:  HP .24  Atk .42  Def .26  SpA .35  SpD .18  Spe .34

   wild kills only      kills    whole EVs   (all six banks)
     10 min             1,020       0
     30 min             3,060       3
     60 min             6,120       9

   elites at 1/500: an elite yields 1 to 3, so each adds 0.002 to 0.006.
     A handful per run is noise; elites move the bank only if many spawn.
   gym mons at 1x: each gym mon beaten adds its full yield, 1 to 3 EVs.
     So gym wins are the main EV source; a run that clears a gym always
     banks something.
   shiny: x2 of its class (a shiny wild is 0.002 per point).

   4 EVs in one stat = +1 at L100, +0.5 at L50 (floor(EV / 4)).

 F1  Rate by enemy class (Jess, 2026-11-04, replaces the flat 1/1000):
       class   rate per yield point   in thousandths   shiny (x2)
       wild    1/1000                 1                1/500
       elite   1/500                  2                1/250
       gym     1x (full yield)        1000             2x
     Every rate is a whole number of thousandths, so the banks stay exact
     integers. One table in copies.js, TUNE before playtesters (BALANCE.md).
     APPROVED in principle; F2 settles the edges.

 F2  Classes come from the flags the kill loop already sees:
       e.gym              -> gym     (gym leader mons)
       e.elite            -> elite
       everything else    -> wild    (golden and thief units included)  REC
     No non-gym bosses exist (checked 2026-11-04): G.Boss.make, the only boss
     spawn, is called only from gym-arena.js, and gym.js says "Gyms are the
     only bosses (2026-10-31)". So the class reads e.gym, not e.boss.
       e.shiny            -> x2 on top of its class
     Elite Four is not built yet; when it is, it uses the gym rate.     REC
     Every kill counts whoever landed it (DoT, bench timing irrelevant).

 F3  When: the allocation screen opens after the run-over screen on a
     death AND on a quit. Debug-flagged runs still allocate.        REC: yes

 F4  Who can receive: the copies in the run's team (up to 6, fainted
     ones included), not the boxes.                                 REC: yes

 F5  Leaving with whole EVs unallocated: one confirm, "N EVs will be
     discarded." Then gone (the draft's discard rule).              REC: yes

 F6  Caps, per Pokemon copy (Jess, 2026-11-04): up to 252 EVs in any
     one stat, up to 510 EVs total across all six. An allocation that would
     pass either is refused; [+] greys out at the cap.          APPROVED

 F7  EVs apply to all six stats, Speed through the movement curve (like
     step 4 D3). Enemies stay at 0 EVs (like D2).                  REC: yes

 F8  Whittling items (EV removal): split into step 5b. Mainline has the
     six EV-lowering berries (Pomeg HP, Kelpsy Atk, Qualot Def, Hondew
     SpA, Grepa SpD, Tamato Spe, -10 each since Gen 4); 5b decides the
     amount, the source (drop, shop, gym reward) and where they are used.
     Until 5b, allocated EVs cannot be removed.               REC: split to 5b

 F9  Sell and Select repeats (changes 3b D10): the sell confirm adds "It
     has N EVs. They are lost." Select repeats keeps team, locked,
     favorite, MOST EVs, best IVs, oldest.                          REC: yes

 F10 A run where every bank is under 1 skips the allocation screen and the
     run-over screen shows one line, "No whole EVs this run", with the six
     fractions it lost. Otherwise the screen opens.                REC: yes
     (at 1/1000 this is most early runs; an empty screen is a dead click)

 FILES  (where, what, why)
=====================================================================

 tools/species_traits.js + regenerated js/data/species-traits.js
   '- each species row gains its six-stat yield (pokeapi pokemon_stats.csv,
      effort); no row: all 0 (a kill banks nothing)

 js/core/stats.js
   '- the profile gains ev (six) from the copy; NEUTRAL gets six zeros;
      attackFactor / applyPlayerDefense pass it into the existing ev slot;
      speedToPx gains an ev argument (default 0)

 js/entities/player.js
   '- statEv(i) beside statIv / statNat; maxHp, maxHpAt, baseSpd, hurt() pass it

 js/entities/enemy.js   the dead-enemy loop, at "pl.kills++" (solo and host)
   '- adds the species yield x its class rate (F1, F2) to the run bank

 js/game.js
   +- the run bank: six integers in thousandths, reset at run start
   +- buildFighter keeps the slot uid on the fighter
   '- endRun hands the bank and the roster's copies to the allocation screen
      (F3); co-op skips it (TODO line)

 js/systems/copies.js
   +- EV_RATE table (thousandths per yield point: wild 1, elite 2, gym 1000;
   |  SHINY_EV 2) and classOf(enemy flags) -> 'wild' | 'elite' | 'gym' (F1, F2)

   '- repeatsIn keep order adds most EVs (F9)

 js/ui/menu.js

 js/core/debug.js

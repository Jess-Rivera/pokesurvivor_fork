 3b-2 EDITS (Jess, 2026-11-04)  -- new rules, approve before the 3b-2 build

 E1  16 characters, not 12. NICK_MAX in copies.js 12 -> 16; clean() already
     caps at NICK_MAX, so old names (12 or fewer) are untouched.
     The copy table in pokebox-plan.md ("Text, 12 characters") updates to 16.

 E2  Cleaning against injection, one function used on typing AND on every save
     load (clean()), so a hand-edited save or a future cloud save is cleaned too:

       typed text
         |  1. keep only the font's Latin set (D6): U+0020 to U+007E, U+00A0 to U+024F
         |     (drops control characters, zero-width and right-to-left marks, emoji)
         |  2. drop the characters that can break out of markup or a string:
         |        <  >  &  "  '  `  \  =  {  }
         |  3. no-break space becomes a space; soft hyphen (U+00AD) is dropped
         |  4. runs of spaces become one; trim both ends
         |  5. cap at 16
         v
       stored nickname (or none: the species name shows)

       Shown only through the existing escape (escHtml) with translate="no", never
       as raw markup. Defense in depth: steps 1 and 2 make the text inert even if
       some later screen forgets to escape it.

     Limit, said plainly: character cleaning stops markup and script injection. It
     cannot stop words aimed at an AI ("ignore your instructions"), since those are
     ordinary letters. Nicknames are only ever displayed, never sent to an AI or a
     server. Cloud phase (deferred): re-clean on the server too; TODO line.

 E3  Filter chips after BST: [heart] Favorites and [padlock] Locked, a new chip set
     in the Team screen filter row (dev.html #ros-filters, after #ros-bst):

       Types ... | Rarity ... | BST ... | [heart] [lock]

     a) Box tabs: a chip on shows only copies with that mark.
     b) Both chips on: copies with EITHER mark (OR), like the other chip sets.
     c) Pokedex tab: the two chips are hidden (marks belong to copies, not species).
     d) Clear resets them; they stay on when you switch box tabs.
     e) The shown-count line counts what the chips leave.

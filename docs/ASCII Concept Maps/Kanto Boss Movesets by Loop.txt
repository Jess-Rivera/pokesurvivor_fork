Planning only. Same method as "Brock Movesets by Loop.txt" (Gym 1 lives there).
Rosters: docs/GYM-ROSTERS.md. Catalog coverage ignored on purpose.

  RULE: each mon walks ITS OWN history with that trainer, weakest set first,
        one step per loop, from the loop it enters (= its slot number) to loop 6.
        Slot 1 needs 6 sets, slot 2 five ... slot 6 one.
        "Weakest first" = the trainer's level in that game, then how optimized
        the set is (PWT and late rematches last).

  SOURCE KEY
  RB      Red/Blue                    Y       Yellow
  FRLG    FireRed/LeafGreen (gym, or E4 first battle)
  FRLG-R  FRLG E4 rematch             GSC     Crystal
  HG      HeartGold/SoulSilver (gym, or E4 first battle)
  HG-R    HGSS rematch (Fighting Dojo for gyms, Indigo Plateau for E4)
  HG-RKT  HGSS Giovanni at Tohjo Falls
  LG      Let's Go gym / E4 first     LG-R    Let's Go rematch
  RKT1/2  Let's Go Giovanni, Rocket Hideout / Silph Co.
  ST1/ST2 Pokemon Stadium (N64) Gym Leader Castle / League, round 1 / 2 (Lv50)
  PK      B2W2 PWT, Kanto Leaders     PW      B2W2 PWT, World Leaders / Type Expert
  PC      B2W2 PWT, Champions         USUM    Ultra Sun/Moon, Rainbow Rocket

  MARKERS
  *   set from another stage/evo of the same line, SAME trainer
      (e.g. Gloom set on Vileplume, Electivire set on Electabuzz)
  +   borrowed from ANOTHER Kanto boss's same species (no canon set exists)
  ^   subset of that trainer's later canon set (early-loop reveal)
  =   held from the loop before (canon sets ran out)
  comp  no canon trainer set exists anywhere; composite from the species

THE LADDER (compareRegion)                                   higher place wins; same place -> tie rule
-----------------------------------------------------------------------------------------------------
 place = (loop, gyms cleared, fighting)        fighting = died inside gym (gyms+1)'s fight
   ... < L1 cleared G2 < L1 died fighting G3 < L1 cleared G3 < L1 died fighting G4 < ... < L2 ...
 same place, both cleared   -> later endTime wins        (survived longer, DR3)
 same place, both fighting  -> earlier reachedAt wins    (got there sooner, DR3)
 exact tie                  -> old record stays
 no old record              -> better, reason "first record for this region"

PACE (pace, read by part D at pause)             k = your gyms this run, B = best.splits
-----------------------------------------------------------------------------------------------------
 no best                              -> none          ("No record yet")
 k >= B.length and k > 0              -> newBest       ("New best pace")
 now > B[k] (best had gym k+1 by now) -> behind, delta = now - B[k]           (the growing gap)
 k > 0                                -> mine[k-1] vs B[k-1]: ahead / behind / even
 k = 0                                -> onPace
 next = { gym: k + 1, at: B[k] } when B[k] exists (the "Next" row)

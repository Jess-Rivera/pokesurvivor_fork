----------------------------------------------------------
  EXCLUSIVE = Stage 3 / BST>=500 species spawn ONLY on map 9.
  Wild pool left for maps 1-8 per tier (cumulative region pool):
             T1   T2   T3   T4   T5   T6         shared:  T5   T6

  SHARED = Stage 3s still spawn on maps 1-8 by type; map 9 just holds ONLY them.

POKEBOX STEP 3a, MICROSTEP 4: FULL BOXES  (plan, 2026-11-04, no code)
Branch: feature/pokeboxes. Spec: docs/proposals/pokebox-plan.md "Rulings for step 3" (full boxes on a pull).
Finishes 3a. Out of scope: lock, favorite, nicknames, bulk sell (3b).

=====================================================================
 TODAY vs AFTER
=====================================================================

 TODAY: every box full -> G.Copies.add drops the copy into the LAST box anyway
        (Box 5 can hold 501, 502, ... no limit)

 AFTER: every box full -> no copy is made. The Pokemon is SOLD on arrival
        at its sell price (15/30/60/120/300, x3 shiny). The Pokedex record
        is still written.

=====================================================================
 A PULL WITH TOO LITTLE ROOM  [Approved ruling, 2026-11-03]
=====================================================================

   click Pull x10, free places = 3  (< 10)
        |
        v
   +--------------------------------------------------------------+
   | Not enough space                                              |
   | You don't have enough space. Any pokemon pulled that can't    |
   | be placed in a slot will be automatically sold.               |
   | 3 free places, 10 Pokemon.                                    |
   |                              [ Pull anyway ]  [ Cancel ]      |
   +--------------------------------------------------------------+
        |                                   |
        v                                   v
   pull runs, never blocked            nothing spent
        |
        v
   all 10 rolled first, then the 3 places go by PRIORITY (D2):
     1. new to the Pokedex   2. shiny   3. higher rarity   4. pull order
   the other 7 are sold on arrival, coins paid at once

   result cards:
   +--------+ +--------+ +---------------+
   | NEW!   | | To Box2| | Box full      |
   |  mon   | |  mon   | | sold +15      |  <- dimmed like a sold card,
   |        | |[Sell+30]| |  (no button)  |     no Sell button
   +--------+ +--------+ +---------------+

   free places >= pull size: no warning, same as today.

=====================================================================
 FULL BOXES DURING A RUN  (rescue, wild shiny)
=====================================================================

   G.onRescue / G.onShinyCaught with every box full
        -> sold on arrival, coins to your saved PokeCoins (D3)
        -> message: "Your boxes are full: <name> was sold for N PokeCoins."
           (new species keep their inherited line, then this line)

=====================================================================
 DECISIONS FOR JESS  (new rules flagged, approve or change)
=====================================================================

 D1  The warning text is the approved one, word for word, plus a count line
     "3 free places, 10 Pokemon."; buttons "Pull anyway" / "Cancel".
     REC: yes

 D2  [NEW RULE] Who gets the free places in a pull: new to the Pokedex first,
     then shiny, then higher rarity, then pull order.
     REC: yes. Alternative: plain pull order (a new 5 star in card 10 would be
     sold while a repeat 1 star in card 1 is kept: feels bad).

 D3  [NEW RULE] Full boxes in a run: a rescue or wild shiny is sold on arrival
     too, and the coins go straight to your saved PokeCoins (not the run's
     coins), so nothing depends on how the run ends.
     REC: yes (same rule as the pull; there is no box screen in a run)

 D4  [NEW RULE] A Pokemon sold on arrival still counts in the Pokedex
     (new species, new shiny, achievements), like selling your last copy.
     REC: yes (matches 3a-3 D1)

 D5  Debug: G.Debug.addCopy with full boxes adds what fits and logs the rest
     as "not added"; it never sells. maxAll is unchanged (1,932 copies fit
     in 5 boxes, 2,500 places).
     REC: yes

 D6  New debug command G.Debug.fillBoxes(leave): tops your boxes up with
     debug copies (Caterpie, 1 star) until `leave` places are free. Saved.
     REC: yes (feel-testing a full box otherwise takes hundreds of pulls)

=====================================================================
 FILES  (where, what, why)
=====================================================================

 js/systems/copies.js
   +- freePlaces(save): sum of (500 - copies) over the boxes you have
   +- add: returns null when every box is full (no overflow into the last box)
   +- priceFor(dex, shiny): the sell price without a copy (for a sale on arrival)
   '- freeBox / add comments updated
   why: the box owns its own capacity

 js/core/db.js  obtain
   '- with no room: record written, coins paid, returns { isNew, uid: null,
      box: null, sold: N }
   why: one path, so the gacha, rescues and wild shinies share D3 and D4

 js/systems/gacha.js  pull
   +- roll all n first (pity, guarantee and shiny as today), then obtain in
      D2 priority order; results stay in pull order for the cards
   '- each result gains sold (coins) when it was sold on arrival
   why: D2 needs every roll known before placing

 js/ui/gacha-ui.js  pull + result cards
   +- before pulling: free places < pull size -> the D1 warning (G.UI.ask)
   '- sold-on-arrival cards: "Box full · sold +N", dimmed, no Sell button

 js/game.js  G.onRescue, G.onShinyCaught
   '- a sold result shows the D3 line (new English string)

 js/core/debug.js
   +- fillBoxes(leave), header line, export
   '- addCopy stops at full and logs (D5)

 After the build (free-edit): changelog (warning, auto-sell), pokebox-plan
 status (3a done) + D2 to D4 rulings, the 3a-2 map's D6 note marked replaced,
 DEVLOG.

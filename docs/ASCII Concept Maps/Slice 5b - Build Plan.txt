1. DATA FLOW
============
  level-up offer ---> pick card ---> TEAM STORE (+1 stack, run state) ---> cards picked +1
                                          |
                                          v
  read move id ---> copy built at the current cards-picked count? --yes--> use it
                                          |no (or no copy yet)
                                          v
  G.MoveDefs[id] (frozen) ---> FOLD from scratch(def, ALL team stacks, cardLock) ---> store copy
                    +---------------------+----------------------+
                    v                     v                      v
             move-sim.js (4 reads)   move-render.js (2)     sheet.js numbers
                    |
                    v
             lens per holder (D36), AFTER the fold
  emitted named child (childOf) ---> folded too (it is the team's move)

  stat-stage timers:  move-effects stat() / statReady ---> caster's team Gate x, Duration x
                      ---> stages.js success(); enemy-caused changes keep base timers

4. DEFAULTS IN THIS PLAN (veto any)
===================================
  emitted named children ...... get the fold (Time Up needs this anyway)
  Vitamins storage ............ own team value read in incOf, NOT the badge path: the badge
                                path loops the roster once, so a later Pokemon would miss it
  flag on, legacy cards ....... not offered; Bubble (unrouted) gets no cards until D-BUBBLE
  rerolls, New Move card ...... unchanged


5. RISKS
========
  readers missed ......... a raw G.MoveDefs read means a card silently does nothing
                           (the mutation runner breaks each read site, see 6)
  Gate card double edge .. Leaf Storm climbs faster AND lasts longer (intended, SS10)
  power spikes ........... Count Up multiplies everything: cap +3 and weight 0.5 hold it
  save ................... none (store is run state, no mid-run save)
  co-op / gyms ........... untouched (routed = single player; gym stacks stay until 7a)

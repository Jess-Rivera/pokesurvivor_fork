  +---------------------------- panel 1520 x 700, centred -----------------------------+
  |  back #181818, 1 px #212121 frame (the detail panel's look)                        |
  |                         (O)     (O)     (O)     ( )     (O)     ( )   96 px circles|
  |                        12/510  40/510  0/510           510/510         18 px text  |
  |                                                                                    |
  |  HP              3     - 12 +  - 4 +2 +  - 0 +           - 0 +                     |
  |  Attack          0     - 0 +   - 36 +   - 0 +            - 252 +                   |
  |  Defense         1     - 0 +   - 0 +    - 0 +            - 6 +                     |
  |  Speed           0     ...                                                         |
  |  Special Defense 0     ...                       64 px rows, 24 px text            |
  |  Special Attack  2     ...                                                         |
  |                                                                                    |
  |                         [   Learn   ]    [  Go Home  ]   SlotButtons, 40 px apart  |
  +------------------------------------------------------------------------------------+

  Columns:  label 300 px (stat name + "left to give")  |  6 team columns x 190 px
  Column order = team slot 1..6. A slot with no copy = empty circle, its cells blank.
  Rows: HP, Attack, Defense, Speed, Special Defense, Special Attack (the hex's clockwise order),
        ALL SIX ALWAYS, even a stat with 0 to give (its + buttons are simply grey).
  Left column number = what is still left to give in that stat (bank minus this screen's adds).

  Cell  "- N +N +"
        N    white   = the copy's EVs in that stat before this screen
        +N   yellow  = what this screen added (hidden at 0); the hex's yellow band colour
        -    grey when this screen added nothing to that cell (old EVs cannot be lowered here;
             lowering is the parked 5b berries)
        +    grey when: that stat has 0 left, OR the cell is at 252, OR the copy is at 510
  "x / 510" under each circle counts the copy's total INCLUDING this screen's adds (live).

FILES AND WHAT CHANGES
=====================================================================================

  js/ui/ev-screen.js  (NEW, G.EvScreen, built like end-run.js on the HUD overlay kit)
     - draws the panel, circles (kit portraitSource / portraitFallback), rows, cells
     - the giving rules move here from run-ui.js showEvs, unchanged in meaning:

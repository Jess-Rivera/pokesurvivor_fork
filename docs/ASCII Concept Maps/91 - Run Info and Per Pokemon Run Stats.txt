DATA FLOW
-------------------------------------------------------------------------
 startRun ---> G.RunStats.create() ---> runTeam.runStats   (run only, never saved)
 hit lands --> Player.onDealt ------> best hit (member + team)     [beside the DPS record]
 enemy dies -> payKill (enemy.js) --> member kill (D1), elite count
 faint ------> Player hurt faint path (run team only, not leaders) -> faint count
 spawn ------> spawner shiny roll ---> shinies seen
 pickup -----> game.js onCollect ----> items (D4)
 run ends ---> endRun ---------------> region record check (D5) -> save
 pause open -> Run Info + Run Stats read once (like the rest of the menu), never per frame

DECISIONS FOR JESS  (D1, D5 change how things are counted or saved: flagged as rules)
-------------------------------------------------------------------------
 D1 per-Pokemon kill credit  RULE
    (a) the Pokemon whose hit finished it  <- rec. Matches the damage rule: a move still in flight after
        a swap credits its caster. Needs a new "last hit by" mark on enemies.
    (b) whoever is on the field when it dies. Simpler, but a swap mid-flight gives the newcomer the kill.
    Either way the TEAM kill count is unchanged.
 D2 "coins" row: (a) coins picked up AND Silver, two rows <- rec  (b) coins only  (c) the end-of-run payout
 D3 shinies: (a) "seen" = shiny enemies that spawned, with "caught" beside it <- rec  (b) caught only
 D4 items: (a) item pickups that offer a choice, plus berries, plus ground items <- rec
           (b) only held and run items
 D5 region record  RULE + NEW SAVE FIELD
    Stored per region. Checked when a run ends (faint or End Run). Better = higher loop, then more gyms
    beaten, then faster time on a tie (spec). Runs flagged by the debug tools (the same flag that keeps a run
    off the ranking) never set a record <- rec. Today the Elite Four does not exist and loop is dev-only, so a
    real run's record is "gyms beaten + time" until those land. Shown as "No record yet" on an empty region.
 D6 EVs shown as: (a) whole EVs (what allocation gives; fractions dropped) <- rec  (b) one decimal

Loop structure: each region has six loops. Loop one, you fight only the first Pokémon of each gym leader and Elite Four member’s roster. Each subsequent loop adds one more from their roster, so loop six is their full team. Twelve boss fights per loop, eight gyms plus Elite Four.

Checkpoints: you get a checkpoint at the end of each loop, so you can start a session at any loop you’ve already cleared rather than needing a six-hour sitting. There’s a separate achievement for clearing all six loops in one sitting.

Legendaries: finishing all six loops lets you choose one legendary from that region to unlock for your roster. No difficulty ramp on repeat clears, since the bullet heaven power curve naturally makes them faster. Legendary fights are bespoke scripted boss fights, and re-challenging one costs an expensive gold toll, balancing deferred. Per-region legendary counts: Kanto and Johto have five each, Hoenn has eight, Sinnoh and Unova have nine each, Kalos has three, and Alola, Galar, and Paldea have eleven each.

Shiny variations: beating all six loops and separately sweeping all of a region’s legendaries each unlock a universal shiny palette-and-effect tier, not per-species recolors, with sparkle or twirl effects possible, and each region’s tiers are visually distinct from the others.

Game tiers: main game, then the secret main game of loops and legendary fights, then end game as collecting every legendary across all nine regions, then a true end game above that.

Arceus: the true end-game superboss, separate from the regional legendaries, gated behind owning every legendary in the game, with its own multi-stage bespoke fight. It’s not catchable, but whichever Pokémon you bring to that fight can pick an inheritor Pokémon, permanently grafting that inheritor’s typing and movepool onto your Pokémon, like an electric-ground Pikachu with Dugtrio’s moveset. This is permanent per individual copy, so different combos need different copies of the same species.

Arceus also unlocks Uber-tier difficulty modifiers above the base eight to ten skull-style modifiers, with the actual Uber modifier content still to be brainstormed.

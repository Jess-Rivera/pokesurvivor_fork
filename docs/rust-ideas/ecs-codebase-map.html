5. How well it fits

Already ECS-shaped

  • Player and leaders share one body with swappable control: a direct Controller component.
  • status.js is "one engine for every host": already a component plus a system.
  • move-sim.js bans canvas, clock and Math.random; move-geom.js is pure math.
  • Elite = wild + mods: one extra component.
  • SimBus already is the event channel; gym.js already uses it.
  • G.Stats is the single formula home: becomes one pure Rust module.
  • log.js already uses preallocated typed arrays.

Needs real design work

  • Enemy's ~109 fields must be split by hand into ~15 components; a lazy port gives one giant component.
  • hurt() and die() mix sim and presentation; the split is the Resolve and Lifecycle stages above.
  • A hit changes attacker and defender at once: Rust forces the DamageEvent queue (Attack writes, Resolve applies).
  • LeaderBrain (belief, memory, planner) is big per-fight state; keep it one component, not many.
  • Collision radius comes from sprite metadata; needs a data table first.
  • ~134 G.Coop branches in sim code disappear; replication reads components instead.
  • Boss brain tells (boss-ai.js) still call FX and the animator directly.

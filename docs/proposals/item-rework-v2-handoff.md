## Gotchas learned this session
- Files have mixed CRLF and LF. Python edits: open with encoding='utf-8', newline='' (the default cp1252 crashes on some files). Heredocs eat non-ASCII; prefer the Edit tool.
- Prettier is enforced (`format: ok` in check.js). Run `npx prettier --write <file>` after editing JS.
- The 7a guard flags `.kind` reads on move objects, hence the `pickup` field in drops.js.
- A gym leader drops TWO items today (it counts as boss and gym, so both death branches fire). This predates our work (confirmed on a copy of the old commit). Left alone, flagged [Open] in docs/ITEMS.md. Bosses also roll the wild extras through dropXp.
- Pokemon-item drops are uniform across the tier, so adding items dilutes the old ones. Ground weights must total 100 (Grounds.TOTAL_W).
- The Pokemon sprite index is GENERATED (js/data/pokesprite-index.js); look up icons as 'hold-item.<name>', 'berry.<name>', 'medicine.<name>', 'battle-item.<name>'.
- Debug on dev.html, not index.html. Headless runs must click #tap-start first. file:// blocks CSS mask-image.
